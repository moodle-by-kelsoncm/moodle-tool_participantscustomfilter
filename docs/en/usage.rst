Usage
=====

1. Open a course and go to *Participants*.
2. The *Filter by profile field* panel appears below the standard filters.
3. Choose a profile field, type all or part of the value and click *Filter*.
4. The matching participants are listed with their identity fields; click a name to open the
   participant's profile in the course. Use the page links when there are more than 20.
5. Click *Clear filter* to remove it.

Without JavaScript the panel is shown at the end of the page and works the same way.

Limitations
-----------

- Suspended enrolments, and enrolments that have not started or have ended, are not listed.
- The panel lists its own results; it does not change the core participants table below it.
