Uso
===

1. Abra um curso e vá em *Participantes*.
2. O painel *Filter by profile field* aparece abaixo dos filtros padrão.
3. Escolha um campo do perfil, digite o valor inteiro ou parte dele e clique em *Filter*.
4. Os participantes encontrados aparecem com os campos de identidade; clique no nome para abrir o
   perfil do participante no curso. Use os links de página quando houver mais de 20.
5. Clique em *Clear filter* para remover o filtro.

Sem JavaScript o painel aparece no fim da página e funciona do mesmo jeito.

Limitações
----------

- Inscrições suspensas, ainda não iniciadas ou encerradas não são listadas.
- O painel lista os próprios resultados; não altera a tabela de participantes padrão abaixo dele.
- O pacote traz só o inglês; a tradução para português vem pelo AMOS.
